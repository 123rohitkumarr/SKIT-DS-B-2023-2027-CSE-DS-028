## 1. Problem Statement

* **A.** People in rural areas face significant difficulties accessing healthcare guidance in their local regional language.
* **B.** Existing healthcare chatbots exclusively support English and formal Hindi, leaving regional Rajasthani dialects underserved.
* **C.** The proposed system utilizes AI, Natural Language Processing (NLP), and speech processing to understand patient symptoms spoken in Hadoti and Marwari and predict possible diseases.

## 3. Proposed Project Sprints

| S. No. | Sprint Name | Proposed User Story of Respective Sprint |
| :---: | :--- | :--- |
| **1** | **Data Collection** | Collect Hadoti & Marwari voice samples across diverse demographic speakers. |
| **2** | **Data Cleaning & Organization** | Preprocess, clean, and organize audio and tabular data for machine learning model training. |
| **3** | **Audio Transcription** | Convert the user's voice input into accurate text using speech-to-text transcription. |
| **4** | **NLP Processing** | Process the user's symptom text using regional NLP techniques and clinical lexicons. |
| **5** | **Disease Prediction** | Develop and train a Machine Learning model that predicts possible diseases based on extracted symptoms. |
| **6** | **Chatbot Development** | Develop an AI chatbot that communicates with users and provides contextual responses. |
| **7** | **UI/UX Development** | Design a simple, intuitive, and user-friendly interface accessible to rural populations. |
| **8** | **Chatbot & Model Integration** | Integrate NLP, disease prediction, and voice processing features into a unified pipeline. |
| **9** | **Model Evaluation & Validation, Response Optimization** | Evaluate the model using Accuracy, Precision, Recall, and F1-score; optimize chatbot responses. |
| **10** | **System Testing & Deployment** | Perform functional integration, usability, and performance testing on the complete application and deploy. |
