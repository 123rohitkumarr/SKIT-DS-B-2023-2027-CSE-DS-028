# Marwari and Hadoti AI Chatbot

### A Regional Language AI Project

An academic project focused on building an AI-based chatbot for **Marwari and Hadoti**, two regional languages spoken in Rajasthan, India. The project aims to explore how Artificial Intelligence, Natural Language Processing (NLP), and voice data can help people interact with technology in their familiar language.

## 1. About the Project

Many people communicate more comfortably in their regional language than in English or Hindi. However, regional languages such as Marwari and Hadoti have limited digital resources for building modern AI applications.

This project aims to address this gap by exploring the development of a chatbot that can work with text and voice data from Marwari and Hadoti.

The main focus is on collecting, organizing, cleaning, and preparing regional-language data for future AI and NLP development. This data can support language understanding, chatbot responses, and voice-based applications.

The project is being developed step by step, starting with dataset preparation and organization before moving towards model development and chatbot integration.

## 2. Problem Statement

Marwari and Hadoti are important regional languages, but creating AI applications for them can be challenging because suitable digital datasets and language resources may be limited.

The key challenges include:

* Collecting useful text and voice data.
* Organizing data in a structured format.
* Preparing transcripts and matching them with the correct language data.
* Reducing unnecessary noise in voice recordings.
* Preparing suitable data for machine learning and NLP tasks.
* Exploring how regional-language AI can support everyday communication.

## 3. Project Objectives

The main objectives of this project are:

1. To collect and organize Marwari and Hadoti text and voice data.
2. To prepare and clean datasets for further processing.
3. To organize transcripts and language-specific data in a structured way.
4. To explore Natural Language Processing techniques for regional languages.
5. To study how machine learning can support regional-language chatbot development.
6. To explore future voice-based interaction and regional-language assistance.

## 4. How the Project Works

The planned workflow is divided into the following stages:

**Stage 1: Data Collection**

Collect relevant text samples, voice recordings, and other suitable language resources for Marwari and Hadoti.

**Stage 2: Data Organization**

Arrange the collected data into appropriate folders and structured files so that it is easier to manage and process.

**Stage 3: Data Cleaning and Preprocessing**

Check the data for missing information, inconsistent formatting, duplicate entries, and unnecessary noise where applicable.

**Stage 4: Transcript Preparation**

Prepare and organize written transcripts associated with the available voice data.

## 7. Dataset Preparation

Dataset preparation is an important part of this project.

The work focuses on:

* Keeping Marwari and Hadoti data properly organized.
* Maintaining transcript files in a structured format.
* Reviewing the quality and consistency of available data.
* Identifying recordings that may need further cleaning.
* Preparing data for future NLP and machine learning experiments.

Voice recordings may contain background noise or other quality issues. These should be reviewed and addressed where possible before using the recordings for model development.
